# ERP AI Assistant（ERP 增强助手）

> Chrome 扩展（MV3）：为跨境电商 ERP 注入 AI 采购建议、调拨建议、采购计划批量生成与利润看板，团队内部日常使用的供应链决策辅助工具。

## 功能

- **AI 采购建议**（采购计划添加页）：自动扫描单据 SKU，结合多市场销售/库存数据给出预测日均与补货建议；数量、风险等级、补货日期全部由前端确定性公式计算，AI 只负责预测与定性判断——结果可复算、可复核
- **AI 调拨建议**（调拨添加页）：按调入仓自动解析目标市场；调出仓缺货时先警示再荐替代仓（含确定性结论句）；建议量超出国内可动用时给出协调警告
- **采购计划生成器**（列表页）：批量按 SKU × 站点生成采购计划，可直接保存为 ERP 草稿，支持 PDF 报告导出与未来库存曲线可视化
- **利润看板**：全渠道净利润汇总与趋势

## 技术要点

- **WXT + TypeScript**，Chrome MV3，Shadow DOM 面板注入 iframe 业务页
- **LLM + 规则引擎混合架构**：LLM 流式输出仅提供销量预测与判断，采购/调拨数量、风险灯、补货日期由确定性公式计算（规避大模型算术不可靠），关键结论前端固定渲染不依赖模型措辞
- **ERP 数据管道**：多市场销售/库存接口分页抓取与聚合（可加指标求和、比率按分量重算）、欧盟 EFN 共享池库存去重、发运管线在途口径、按站点借用的库存口径
- **工程化**：严格 TDD（330+ 单测）、CI（测试 + 构建 + 类型错误基线棘轮门禁）、版本化发布与内网自动更新

## 运行

```bash
npm install
npm run build     # 产物在 dist/chrome-mv3，chrome://extensions 开发者模式加载
npm test          # 全量单测
```

使用需自行配置 LLM API Key（DeepSeek 兼容接口）。
